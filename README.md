### 📊 Satria Data — Stunting Intervention Mapping

A Data Science project developed for the **Satria Data Statistics Essay Competition**, focusing on identifying regional patterns and intervention priorities for stunting in Indonesia.

The project integrates socio-economic and sanitation-related data and applies **K-Means Clustering** to identify different regional profiles and support data-driven intervention recommendations.

**Tech:** Python • Pandas • Scikit-learn • K-Means • Data Analysis

---

### 🧠 Generative Adversarial Network

An experimental Deep Learning project exploring **Generative Adversarial Networks (GANs)** and evaluating generated results using quantitative metrics.

The project focuses on understanding the GAN training process, image generation, and model evaluation.

**Tech:** Python • PyTorch/TensorFlow • Deep Learning • GAN

---

### 📈 Time Series Forecasting

A collection of time series forecasting projects exploring the use of **Long Short-Term Memory (LSTM)** networks for financial market data.

Projects include data preprocessing, sequence generation, model training, evaluation, and comparison of predicted and actual values.

**Tech:** Python • Pandas • TensorFlow • LSTM • Time Series Analysis
